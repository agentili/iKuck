## Notes

- `casa` in ADR-003 terminology = `house` scope in this codebase (`house_memberships`, `houses`, `houseId`, scope `house:${string}`); there is no separate "casa" concept (see inventory note at `docs/bring-to-pantry-code-inventory.md:91`).
- Schema changes went through Drizzle migrations (`0008_bring_connections`, `0010_pantry_candidates`), not TypeScript-only edits (`docs/bring-to-pantry-code-inventory.md:93`).
- `pantry_lot` is the only sync entity touched by this chain, written on candidate accept (`candidatesRepository.ts:213–218`); candidates themselves are never sync entities.
